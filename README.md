# 📊 GPA Analyzer - 成绩分析与 GPA 计算器

> 命令行工具 + Web 界面,读取成绩单,自动计算 GPA、加权平均分,生成趋势图和雷达图。
> 支持多高校绩点规则,可在线测试对比学校给出的绩点是否一致。

## ✨ 功能

- 📄 读取 CSV / Excel 成绩单(兼容多种列名格式)
- 🧮 计算 GPA、加权平均分
- 🏫 **多学校绩点规则支持**:内置常用规则预设,一个 JSON 文件即可添加任意学校(4.0制/5.0制/断崖式均可)
- 📈 各学期 GPA 和加权平均分趋势分析
- ⚠️ 自动识别薄弱课程(低于 70 分的课程)
- 🥧 学分分布饼图、🕸️ 成绩雷达图
- 🖥️ 终端美化输出(表格、颜色标注)
- 🌐 **Web 在线版**:浏览器打开即用,无需安装,支持手动输入课程,数据自动保存

## 🚀 快速开始

### 方式一:Web 在线版(推荐,无需安装)

👉 **[在线体验](https://gpa-analyzer-np8csp8jcxmompy2aygep9.streamlit.app/)**

直接打开链接,选择绩点规则 → 上传成绩单或手动输入 → 查看 GPA → 对比学校给出的绩点。

### 方式二:命令行版

#### 1. 安装 Python

从 [python.org](https://www.python.org/downloads/) 下载安装,安装时**务必勾选 "Add Python to PATH"**。

安装后在终端验证:

```bash
python --version
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 运行

```bash
# 使用内置的示例数据(无需自己的成绩单也能体验)
python main.py

# 使用自己的成绩单
python main.py 我的成绩单.csv

# 使用某个学校的绩点规则(见下方"多学校支持")
python main.py --school 标准5.0制

# 只看终端输出,不生成图表
python main.py --no-chart
```

运行后会:
- 在终端显示总体统计、各学期分析、全部课程明细
- 在 `output/` 文件夹生成趋势图、饼图、雷达图

### 完整参数列表

| 参数 | 说明 |
|------|------|
| `file` | 成绩单文件路径(.csv/.xlsx),不填用示例数据 |
| `-s, --school 名称` | 使用 configs/ 中的学校规则预设 |
| `-c, --config 路径` | 使用自定义规则 JSON 文件(优先于 --school) |
| `--list-schools` | 列出所有可用的规则预设 |
| `--show-rules` | 显示当前规则的成绩-绩点对照表 |
| `--no-chart` | 不生成图表 |

## 🏫 多学校绩点规则支持

不同学校的绩点制度不同,本项目把规则抽成了 JSON 配置文件:**加一所新学校 = 加一个 JSON 文件,不用改任何代码**。

```bash
# 查看所有内置规则
python main.py --list-schools

# 使用 5.0 满绩制
python main.py --school 标准5.0制
```

内置预设(`configs/` 文件夹):

| 预设 | 说明 |
|------|------|
| 标准4.0制(细分) | 每3分一档的4.0制(默认) |
| 简洁4.0制 | 每10分一档的断崖式4.0制 |
| 标准5.0制 | 满绩5.0 |
| 我的学校(模板) | 自定义模板,复制后修改 |

### 添加你的学校

1. 复制 `configs/我的学校(模板).json`,重命名为你学校的名字
2. 按教务处的《绩点计算办法》修改 `rules`(每行是 `[分数下限, 绩点]`,从高到低)和 `scale`(满绩点)
3. 运行 `python main.py --school "你的学校名" --show-rules` 核对规则表

配置文件格式:

```json
{
    "name": "我的学校",
    "scale": 4.0,
    "description": "可选说明",
    "rules": [
        [90, 4.0],
        [80, 3.0],
        [70, 2.0],
        [60, 1.0],
        [0, 0.0]
    ],
    "等级成绩映射": {
        "优秀": 95, "良好": 85, "中等": 75, "及格": 65, "不及格": 50
    }
}
```

> ⚠️ 内置预设是常见规则的整理,**具体分档请以你学校教务处公布的规定为准**,发现不一致欢迎提 PR 补充更多学校。

## 📋 成绩单格式要求

你的 CSV / Excel 文件需要包含这四列(列名可以是以下任一写法):

| 标准列名 | 兼容写法 |
|---------|---------|
| 学期 | 开课学期、term、学期名称 |
| 课程名 | 课程名称、课程、科目、course |
| 学分 | credit、credits |
| 成绩 | 分数、总评成绩、score、grade |

支持百分制(如 `92`)和五级制(如 `优秀`、`良好`、`及格`、`不及格`)。

CSV 示例:

```csv
学期,课程名,学分,成绩
大一上,高等数学I,5,92
大一上,大学英语I,3,87
```
