## 第一课:安装环境(30分钟)

### 1.1 安装 Python

1. 打开浏览器,访问 https://www.python.org/downloads/
2. 点击黄色按钮 "Download Python 3.x.x"
3. 运行下载的安装程序
4. **最重要的一步**:勾选底部的 **"Add Python to PATH"** (不勾的话终端里找不到 python 命令)
5. 点击 "Install Now",等待安装完成

验证安装成功:
- 按 `Win + R`,输入 `cmd`,按回车,打开命令提示符
- 输入 `python --version`,回车
- 如果显示 `Python 3.x.x`,说明安装成功

### 1.2 安装 VS Code 扩展

1. 打开 VS Code
2. 点击左侧边栏的"扩展"图标(四个方块组成的图标,或按 `Ctrl+Shift+X`)
3. 搜索 `Python`,安装微软官方发布的那个(作者显示 "Microsoft")
4. 搜索 `Jupyter`,也安装微软官方的(可选,以后有用)

### 1.3 安装项目依赖

打开终端(VS Code 中按 `` Ctrl+` `` 打开),输入:

```bash
cd "你的项目文件夹路径"
pip install -r requirements.txt
```

这会自动安装 pandas(处理表格)、matplotlib(画图)、rich(美化终端输出)。

## 第二课:理解这个项目(20分钟)

### 2.1 Python 是什么?

Python 是一种编程语言。你写一段文字描述"做什么",Python 解释器就帮你执行。

这个项目里有几个 `.py` 文件,每个文件就是一段 Python 程序:

| 文件 | 作用 | 一句话解释 |
|-----|------|-----------|
| `main.py` | 入口 | 程序从这里开始运行,调用其他模块 |
| `utils.py` | 读数据 | 把你的成绩单变成程序能处理的表格 |
| `gpa.py` | 算绩点 | 把分数换算成 GPA |
| `rules_loader.py` | 读规则 | 从 configs/ 加载不同学校的绩点规则 |
| `analyzer.py` | 做分析 | 按学期统计、找薄弱课程 |
| `report.py` | 画图表 | 把分析结果画成图保存下来 |

### 2.2 几个核心概念(看代码前先了解)

- **变量**: 存数据的盒子,比如 `score = 92` 就是把 92 存进叫 score 的盒子
- **函数**: 封装好的操作,比如 `calc_gpa(df)` 就是"帮我算 GPA",你不用管内部细节
- **列表/字典**: 存多个数据的容器,列表用 `[]`,字典用 `{}`(键值对)
- **DataFrame**: pandas 提供的"超级表格",可以像 Excel 一样按列筛选、计算

## 第四课:上传到 GitHub(30分钟)

### 4.1 注册 GitHub

1. 访问 https://github.com ,点击 "Sign up"
2. 注册一个账号(用户名选一个专业的,面试时用得到)

### 4.2 安装 Git

1. 访问 https://git-scm.com/download/win ,下载安装
2. 安装时一路默认即可

### 4.3 创建仓库并推送

在终端中执行(替换成你的 GitHub 用户名):

```bash
cd "C:\你的路径\gpa-analyzer"

# 告诉 Git 你是谁(只需做一次)
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"

# 初始化本地仓库
git init

# 把所有文件加入跟踪
git add .

# 做第一次提交(记录当前状态)
git commit -m "初始提交:成绩分析工具v1.0"

# 在 GitHub 上创建远程仓库(需要输入用户名和token)
git remote add origin https://github.com/你的用户名/gpa-analyzer.git
git branch -M main
git push -u origin main
```

完成后访问你的 GitHub 页面,就能看到项目了!

## 常见问题

**Q: 运行报 "No module named 'xxx'"?**
A: 依赖没装好,重新运行 `pip install -r requirements.txt`

**Q: 图表中文显示为方块?**
A: Windows 系统一般有黑体(SimHei)。如果仍有问题,打开 `report.py`,把 `_FONT` 改成 `"Microsoft YaHei"`

**Q: 我的成绩单格式不对怎么办?**
A: 用 Excel 打开成绩单,确保有"学期""课程名""学分""成绩"四列,另存为 CSV 即可

**Q: 如何自定义绩点规则(比如我们学校是5.0制)?**
A: 复制 `configs/我的学校(模板).json`,改个文件名,按教务处的规定修改里面的 `rules` 和 `scale`,然后运行 `python main.py --config "你的文件.json"`。也可以直接 `--school 文件名` 选择 configs/ 里已有的预设,`--show-rules` 可以核对规则表

**Q: 怎么看有哪些预设规则?**
A: 运行 `python main.py --list-schools`
